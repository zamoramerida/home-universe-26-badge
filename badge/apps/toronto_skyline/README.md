# Toronto Skyline

A tiny Toronto skyline with the CN Tower, city lights, and three skies inspired by dawn, day, and night.

## Usage

Open **Toronto Skyline** from the badge menu.

| Button | Action |
| --- | --- |
| Left / Right | Change between dawn, day, and night |
| Select | Toggle the Toronto postcard caption |
| Home | Return to the badge menu |

The skyline is drawn with the badge's built-in graphics API; no external images, network, or extra hardware are required.
