# Toronto Skyline

A tiny Toronto skyline with the CN Tower, city lights, and tilt-reactive parallax across dawn, day, and night.

## Usage

Open **Toronto Skyline** from the badge menu.

| Button | Action |
| --- | --- |
| Left / Right | Change between dawn, day, and night |
| Select | Toggle the Toronto postcard caption |
| Tilt | Shift the skyline, sun or moon, and lake reflections with subtle parallax |
| Home | Return to the badge menu |

The app samples the built-in IMU and calibrates the neutral view when opened. Tilt gently to explore the scene; motion is smoothed and limited to a few pixels. No external images, network, or extra hardware are required.
